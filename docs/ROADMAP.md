# ロードマップ

各段階の「次へ進む条件」を満たしたら次へ進む。決まったこと（2026-11-11 satou さん）: 新しいリポジトリ、独自の名前「宝石商の工房」と自作カード、2人対戦のみ。

1. **土台** — 準備スクリプト・確認コマンド・CI・PR の決まりをカルカソンヌ版から写す。
   - 次へ: CI が緑。
2. **ルールエンジン** — 公式ルールどおり（伏せ予約・チップを戻す・貴族・一巡で終わり・同点の判定）。自作カード90枚（`src/gem_merchant/cards.py`）と正解版のエンジン（`game.py`）。
   - 次へ: ルールの細部とランダム対局の不変条件をテストで押さえる（2026-11-12 済み）。速い版と全手の照合は、探索が遅いと分かった段階3で作る。
3. **基準 AI と対戦ページ** — 手作り評価と仮決め MCTS。ブラウザの対戦ページとルール入門を GitHub Pages で公開（スマホ幅・PC幅の点検つき）。
   - 次へ: MCTS が手作り評価に大きく勝ち越す（2026-11-12 済み: 2000回で勝率0.93、docs/EXPERIMENTS.md）。スマホ幅で対戦できる（対戦ページは次の PR）。
4. **学習で強くする** — 自己対戦で評価を学ぶループとチャンピオンの自動更新。公開実装（lapidary・cestpasphoto）を手元で相手にして測る。
   - 次へ: 公開実装に勝ち越す。頭打ちなら AlphaZero 型を試す。
5. **学習ページ** — 戦略・AI のコツ・次の一手クイズ・データ（先手有利など）。本文の言い切りは集計で検査。日英対訳。
6. **人との比較** — 人との対局で強さを確かめる。

## 並行: GTO（均衡）の研究

2026-11-12 satou さんの依頼。2人・ゼロ和で、隠れているのは山札の順と相手の伏せ予約だけなので、終盤（山札が少ない・15点が近い）は期待値つきの読み切り（expectiminimax）で正確に解ける見込み。
その解き手を物差しにして、AI の手が最善からどれだけ外れているか（損失）を測る。carcassonne-research の GTO 研究と同じ考え方。
