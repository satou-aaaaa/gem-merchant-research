## ルールの要点（2人対戦）

公式ルールブック（Space Cowboys、10周年版・英語）で確かめた: https://spacecowboys.fr/_files/ugd/59baa2_00997b64c555405c8df90c4c8bf9f4ec.pdf

| 項目 | 中身 |
| --- | --- |
| 部品 | 宝石5色×7枚、金（万能）5枚、カード90枚（レベル1: 40・2: 30・3: 20）、貴族10枚 |
| 2人の準備 | 宝石は各4枚（金は5枚のまま）。貴族は3枚。各レベル4枚を表向きに並べる |
| 手番（1つ選ぶ） | 違う色3枚を取る（足りなければ2枚・1枚。金は不可）／同じ色2枚を取る（取る前に4枚以上あるときだけ）／予約して金1枚（場の表向きか山札の一番上を伏せて。3枚まで。金が無くても予約はできる）／カードを買う（場か自分の予約札。払ったチップは場に戻る） |
| 割引 | 持っているカードはその色を1枚分ずっと値引きする。余ってもチップはもらえない |
| 貴族 | 手番の終わりに条件（持っているカードの色と枚数）を満たすと来る。行動ではない。1手番に1枚、複数なら選ぶ |
| チップの上限 | 手番の終わりに10枚を超えたら、好きなものを戻して10枚にする |
| 終わり | 手番の終わりに15点以上で、その一巡を最後までやる（全員が同じ回数） |
| 勝ち | 点が多い人。同点なら買ったカードが少ない人。それも同じなら引き分け |

貴族は断れない・1手番に1枚・最後の手番でも来る（公式ライセンスのルール集 Dized の [貴族のルール](https://rules.dized.com/splendor/rule/gameplay/visit-from-a-noble) と [FAQ](https://rules.dized.com/game/vdDSzuu4RsC8F45PsW0TKw/faq)、2026-11-12 確認）。
ルールに書いていない細部をエンジンがどう決めたかは `src/gem_merchant/game.py` の先頭に書いた。

見えない情報は2つ: 山札から何が出るか、相手の伏せ予約札。

多くの公開実装はルールを簡略化している（伏せ予約を公開、貴族を自動で選ぶ、取りながら戻す手が無い）。

## AI の作り方の方針

1. 手作り評価＋貪欲（比べる基準）
2. 仮決め MCTS＋自己対戦で学ぶ線形評価（カルカソンヌ版で公開手法に勝った構成。最初の本命）
3. 頭打ちなら AlphaZero 型

一手の候補はだいたい45通り以下、1局は各1人約20〜30手（[BGA のコツ](https://en.doc.boardgamearena.com/Tips_splendor)では17〜28手）なので、カルカソンヌより学習が速く回る見込み。
「取る」と「戻す」はまとめて一手にする。終盤の「あと1手で終わる」局面は全部読む探索を足す。

## 学びどころ（サイトで教えること）

チップよりカード（割引）／安いカードから高いカードへの切り替え時／予約の使い方／色を絞る／貴族を狙うか捨てるか／15点の一巡ルールでの数え切り／先手有利の大きさ（数字の公開資料が見つからなかった。AI の大量対局で示せる）。
